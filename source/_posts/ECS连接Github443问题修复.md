# 原因
大陆地域服务器访问GitHub会受到国际链路影响，导致时断时续，甚至无法访问，此类问题没有较好的解决办法。
# 解决办法
1. 可以稍等多刷新几次后再去测试下，
2. 或者在其他可以访问的客户端下载后，再上传到服务器上。
3. 140.82.114.3这个节点的时候可以访问，您可以尝试在/etc/hosts中添加
```shell
vim /etc/hosts
140.82.116.4 github.com
```
